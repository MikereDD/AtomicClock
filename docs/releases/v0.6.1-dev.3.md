# Atomic Clock v0.6.1-dev.3

First secure download/install updater milestone.

## Added

- App-controlled update staging under Atomic Clock's cache directory.
- Exact APK and detached-signature size enforcement while downloading.
- SHA-256 verification of the downloaded APK and `.apk.sig`.
- RSA/SHA-256 detached signature verification using the embedded, fingerprint-pinned public key.
- Android package archive inspection before install.
- Exact package-ID verification.
- Exact APK signing-certificate verification against Atomic Clock's pinned certificate.
- Exact APK version verification against the signed release manifest.
- Final repeat of all cryptographic/package checks immediately before installer handoff.
- Android system package-installer handoff through a private `FileProvider`.
- Android 8+ unknown-app-source permission flow.
- Download/verifying/ready/installing states in Settings.

## Security behavior

Any mismatch in origin, size, SHA-256, detached signature, package ID, version,
release-key identity, or APK signing certificate fails closed. Atomic Clock never
silently installs an APK.

## Test sequencing

This build is the first updater capable of installing a newer Development build.
After dev.3 is published as a GitHub prerelease, dev.4 should be published as the
first real end-to-end update target.
