# Atomic Clock v0.6.0

Atomic Clock v0.6.0 hardens background reliability and introduces the precision Dial widget family.

## Highlights

- Battery-conscious NTP, weather, and location refresh behavior.
- Precision Dial widget built around a single verified mechanical geometry.
- Four selectable Dial themes: **Midnight**, **Arctic**, **Retro Brass**, and **Emerald**.
- Theme-specific face artwork and matching live clock hands where applicable.
- Polished date, weather, humidity, and drift complication hierarchy.
- Responsive Dial sizing across compact, normal, and large widget placements.
- Existing Classic widget remains available.

## Install

Download the signed `AtomicClock-v0.6.0.apk` asset from the GitHub Release and install it on Android 8.0 (API 26) or newer.

## Verification

The release also includes `SHA256SUMS.txt`, `VERIFY.txt`, and `release-manifest.json` so the binary checksum and signer identity can be checked independently.
