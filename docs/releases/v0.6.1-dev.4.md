# Atomic Clock v0.6.1-dev.4

First dedicated end-to-end updater target.

## Purpose

This development build intentionally makes no trust-model changes from
v0.6.1-dev.3. It exists as a newer, properly signed Development-channel release
so an installed dev.3 build can exercise the complete updater path:

- discover a newer Development release
- validate the schema-2 manifest
- download the APK and detached `.apk.sig`
- enforce expected sizes
- verify both SHA-256 digests
- verify the RSA/SHA-256 detached release signature
- verify Atomic Clock package identity and version
- verify the pinned Android APK signer certificate
- repeat verification at the final trust boundary
- hand the verified APK to Android's system package installer

A successful dev.3 → dev.4 update proves the complete updater pipeline on-device.
