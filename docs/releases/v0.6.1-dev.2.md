# Atomic Clock v0.6.1-dev.2

Updater security hardening milestone.

## Added

- Permanent Typezer∅ detached release-signing identity for Atomic Clock.
- RSA/SHA-256 detached `.apk.sig` generation.
- Immediate detached-signature verification during release builds.
- Schema-2 release manifests with updater protocol compatibility and source provenance.
- Locally pinned release signing-key ID and SPKI SHA-256 fingerprint.
- Embedded public release key only; private release key remains outside the repository.
- Runtime RSA/SHA-256 signature-verification utility for the upcoming download/install stage.
- Strict manifest checks for APK name, signature name, sizes, SHA-256 values, release key ID, and public-key fingerprint.
- Automatic Stable/Development release-channel inference from the version string.
