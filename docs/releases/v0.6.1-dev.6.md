# Atomic Clock v0.6.1-dev.6

Dedicated updater-hardening validation target.

## Purpose

This development release intentionally makes **no updater trust-model changes**
from v0.6.1-dev.5.

It exists as a newer, correctly signed Development-channel release so an
installed dev.5 build can validate the hardening changes added in that milestone.

## Validation path

From Atomic Clock v0.6.1-dev.5:

- Select the **Development** update channel.
- Check for updates.
- Discover v0.6.1-dev.6.
- Download the APK and detached `.apk.sig`.
- Observe the visible **Verifying** state.
- Verify exact asset sizes and SHA-256 values.
- Verify the RSA/SHA-256 detached release signature.
- Verify package ID, version, and pinned APK signing certificate.
- Test Android's per-app install permission flow.
- Grant permission and use **Continue installation**.
- Cancel Android's installer once and confirm the update can be retried.
- Complete the normal signed upgrade to dev.6.
- Confirm settings and widget state survive the upgrade.
- Confirm staged update files are cleaned after the new version starts.
